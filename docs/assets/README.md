# README banner

`gtracker-banner.png` was generated with the built-in image-generation tool on
2026-10-30 at the owner's request. It is illustrative artwork, not an application
screenshot or a photograph of hardware. The selected output is used unchanged.
Its exact SHA-256 is allowlisted in `tools/repo_guard.py`; other binary assets
remain subject to the repository's normal checks.

## Generation prompt

Use case: ads-marketing. Asset: wide GitHub README banner for gtracker, a C64 SID
music tracker. Create a finished restrained graphic with the feel of a small
independent European computer music magazine advertisement printed in 1987,
designed by someone who actually used a Commodore 64. Landscape 3:1 composition.
Flat midnight blue ink background, warm ivory and muted C64 light blue, tiny
faded red accent. Large left-aligned lowercase bitmap lettering exactly
'gtracker'; underneath small monospaced text exactly 'THREE VOICES. STILL ENOUGH.'
Right half: spare woodcut / coarse halftone illustration of a beige breadbin-style
1980s home-computer keyboard seen from above at a slight angle, with three thin
stepped oscillator traces running horizontally behind it. Bold clean silhouette,
deliberate negative space, slightly imperfect ink registration, very light paper
grain. Elegant and readable at small GitHub width, no busy collage. No glowing
neon, no purple gradient, no chrome, no space scene, no robots, no photorealistic
render, no fake app screenshot, no watermark, no extra words. Final image should
feel like a real modest period print design, not a modern retro-futuristic gaming
advertisement.
