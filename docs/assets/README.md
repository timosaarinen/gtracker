# README banner

`gtracker-banner.png` was generated with the built-in image-generation tool on
2026-10-30 at the owner's request. It is illustrative artwork, not an application
screenshot or a photograph of hardware. The selected output is used unchanged.
Its exact SHA-256 is allowlisted in `tools/repo_guard.py`; other binary assets
remain subject to the repository's normal checks.

The current revision uses the built-in image editor with the first banner as
reference. It replaces the navy with C64-style blue and adds distinct pulse,
sawtooth and triangle traces. The image is 2172 x 724. Generated background pixels
vary slightly around the requested #352879; the website feathers the outer edges
with CSS masks into its exact background color. No pixel editing was applied.
